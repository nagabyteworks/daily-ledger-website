# Content Placeholder Checklist

Before launching the website, search all HTML files for these placeholders and replace them with the actual values.

## Global / Business Information
- [ ] `[LEGAL ENTITY NAME]` (e.g., Nagabyte Inc., or an individual's name if acting as a sole proprietor)
- [ ] `[BUSINESS ADDRESS]` (Physical mailing address, required for some app stores)
- [ ] `[SUPPORT EMAIL]` (e.g., admin@nagabyte.com)
- [ ] `[PRIVACY CONTACT EMAIL]` (Can be the same as support, e.g., privacy@nagabyte.com)

## App Links
- [ ] `[GOOGLE PLAY URL]` (The actual URL to the Daily Ledger app on the Google Play Store)

## Legal Documents (Privacy Policy & Terms)
- [ ] `[LAST UPDATED DATE]` (Set this to the current date when publishing)
- [ ] `[JURISDICTION]` (e.g., "State of California", "United Kingdom", "India")
- [ ] `[VERIFY AGE LIMIT]` (Minimum age to use the app, e.g., 13 or 18)

## Technical Features / Product Claims
Ensure these badges and tags are removed or verified:
- [ ] `[Planned]` or `[Planned / Verify Status]` (For features like Bank Statement Import)
- [ ] `[VERIFY BEFORE PUBLICATION: ...]` (Various technical implementation details in the Privacy Policy)
- [ ] `[VERIFY AI PROVIDER DATA RETENTION POLICY]` (If using an LLM to parse bank statements)
- [ ] `[LEGAL REVIEW REQUIRED]` (General warning that a lawyer should read the Terms)
- [ ] `[VERIFY IF APPLICABLE]` (For things like Subscriptions in the support page)
